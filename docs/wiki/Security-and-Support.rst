Security and support
====================

Demo safety
-----------

Use fictional contact information only. This browser demo does not transmit
requests, persist personal data, or accept payments. No safety certification,
real stock availability, or commercial warranty is implied by its sample copy.
Do not add real customer data, credentials, or private business records.

Report a vulnerability privately
--------------------------------

If GitHub private vulnerability reporting is enabled, use the repository's
Security tab to report privately. Do not assume it is enabled. Otherwise,
ask a maintainer in a public issue for a private reporting channel without
including exploit details or sensitive information. Never post secrets in
an issue or pull request.

Include affected files, reproduction details, impact, and a suggested
mitigation in the private report. If a credential is accidentally disclosed,
revoke it immediately; deleting it from the latest file does not revoke it
or remove it from history.

Get help
--------

Read `Deployment <Deployment.rst>`_ for local setup problems. For other
non-sensitive questions, search existing GitHub issues first, then open an
issue describing your environment and what you have already tried. There is
no support SLA for this demo.

Product roadmap
---------------

The GitHub issue tracker is the working backlog. Proposed work includes
catalogue accessibility verification, age-based filtering, wholesale request
integration, and automated browser regression coverage. These are enhancements,
not promises of production readiness. There is no published release schedule.
