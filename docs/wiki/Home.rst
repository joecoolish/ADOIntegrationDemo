Little Works Developer Wiki
==========================

Welcome! Little Works is a fictional wooden-toy manufacturer. This repository
demonstrates a small web project and provides work items suitable for discussing
GitHub and Azure DevOps integration. No integration is configured automatically.

Start here
----------

1. Follow `Deployment <Deployment.rst>`_ to run the demo locally.
2. Read `Architecture <Architecture.rst>`_ to understand the application.
3. Follow `Contributing <Contributing.rst>`_ for your first pull request.
4. Use `Quality <Quality.rst>`_ before requesting review.
5. Consult `Security and support <Security-and-Support.rst>`_ when reporting problems.

Project boundaries
------------------

This is a browser-only prototype. The catalogue is fictional and fixed. Requests
are previews, not emails or orders. Production commerce, verified toy safety
information, wholesale pricing, inventory, and authentication are out of scope.

Documentation ownership
-----------------------

These repository-backed Wiki pages are reviewed alongside code. Update affected
pages in the same pull request as behavior changes. A maintainer may publish
them to GitHub Wiki; the source of truth remains this directory. Relative links
here target repository files; when publishing, adapt links to Wiki page names.
